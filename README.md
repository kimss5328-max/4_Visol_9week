# Subject 9 Machine Vision

OpenCV 기반 제조 머신비전 검사기술을 단계적으로 학습하는 프로젝트입니다.

## Day 01 — 머신비전 검사문제 설계와 ROI (2026-10-23 / 김도은)
1일차에는 완성된 OK / NG 검사기를 만드는 것이 아니라
이미지와 영상에서 **어디를 검사할 것인지 정하고,
정상과 불량의 차이를 어떻게 측정 가능한 특징으로 바꿀 것인지**
생각하는 과정을 학습했습니다.

### 핵심 흐름

```text
검사 문제 확인
    ↓
이미지 읽기
    ↓
ROI 설정
    ↓
여러 이미지에 같은 ROI 적용
    ↓
영상 Frame 처리
    ↓
영상 Frame에 ROI 적용
    ↓
스마트폰 실시간 영상 연결
    ↓
실시간 Frame에 ROI 적용 (마우스 드래그로 선택)
    ↓
병뚜껑 검사 문제에 ROI 직접 적용
    ↓
결과와 판단 기록
```

### 작성한 코드

| 파일 | 역할 |
|---|---|
| `00_check_env.py` | Python · OpenCV · NumPy 환경 확인 |
| `01_read_image.py` | 이미지 한 장 읽기 |
| `02_image_info.py` | 이미지 크기와 채널 확인 |
| `03_roi_crop.py` | 이미지 한 장에서 ROI 설정·저장 |
| `04_batch_roi.py` | 여러 이미지에 동일한 ROI 적용 |
| `05_video_input.py` | 저장 영상을 Frame으로 읽고 일정 간격으로 저장 |
| `06_video_roi.py` | 저장 영상의 Frame에 ROI 적용·저장 |
| `07_webcam_input.py` | 스마트폰 IP Webcam 영상 입력 확인 |
| `08_phone_camera_roi.py` | 실시간 영상에서 마우스로 ROI 선택, `cap_on.jpg` / `cap_off.jpg` 저장 |

### 확인한 결과

- 병뚜껑 유무 검사를 대상으로 ROI를 1차 → 3차까지 조정했습니다.

| 시도 | x1 | y1 | x2 | y2 | 결과 |
|---|---|---|---|---|---|
| 1차 | 50 | 50 | 350 | 300 | 일부 이미지에서 검사 대상이 잘림 |
| 2차 | 50 | 50 | 500 | 300 | 대상은 포함되나 배경이 너무 많음 |
| 3차 | 50 | 50 | 400 | 275 | 배경을 줄이기 위해 축소 |

- 한 이미지에서 잘 맞는 ROI가 다른 이미지에서는 맞지 않을 수 있음을 확인했습니다.
  병의 위치와 크기가 이미지마다 달라서 고정 ROI의 한계를 발견했습니다.
- 저장 영상과 스마트폰 실시간 영상도 OpenCV에서 Frame 단위로 처리된다는 것을 확인했습니다.
- 실시간 영상에서는 좌표를 코드에 넣지 않고 마우스 드래그로 ROI를 선택했습니다.
